# 数学与 AI 术语 · 词源对照

43 个数学和 AI 常用术语，每个词讲清楚四件事：人话、英文释义、英文来源、中文来源。另外附一段「💭 怎么来的」，还原这个词被造出来之前的故事：当时大家在解决什么问题、做了什么，最后为什么借了这个词来命名。

理解一个概念，靠的是回到它被命名之前，而不是去抠字面意思。

## 文件

- `数学与AI术语_词源对照.md`：笔记本体，普通 Markdown，任何编辑器都能读
- `term-origin.css`：Obsidian 样式片段。阅读视图下窗口够宽时，「💭 怎么来的」挂在正文右侧当旁注；窗口窄时收成折叠栏

## 在 Obsidian 里使用

1. 把 `数学与AI术语_词源对照.md` 放进你的库
2. 把 `term-origin.css` 放进库里的 `.obsidian/snippets/`
3. 设置 → 外观 → CSS 代码片段，打开 `term-origin`

样式只对 frontmatter 里带 `cssclasses: [term-origin]` 的笔记生效，不影响其他笔记。旁注切换的阈值（960px）和宽度（30cqw）可以在 CSS 里改。
